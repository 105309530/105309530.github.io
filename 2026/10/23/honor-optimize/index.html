honor optimize

  • 2026-10-23

测试设备：荣耀 Magic6（BVL-AN00），MagicOS 10.0.0.120，Android 16 / API 36。
修改系统组件有可能引起升级异常、系统功能失效，甚至需要电脑协助。操作前备份数据、确保 USB 调试和电脑 ADB 已授权。
不要直接删除系统 APK、关闭底层热保护或照搬其他版本 Binder 事务编号。
请自行权衡利弊，若造成损失概不负责！
以下是个人设备的操作记录，不保证适用于其它荣耀机型或系统版本。

一、工具准备：

手机：Shizuku、Termux

四、解除降帧:

荣耀手机经常出现温度升高后降低性能与帧率的情况，经研究发现与HnAps组件有关。

CPU 核心 冷机策略上限 热机策略上限 下降幅度
CPU0、1 2.266 GHz 1.805 GHz 约 20.3%
CPU2、3、4 3.149 GHz 2.573 GHz 约 18.3%
CPU5、6 2.957 GHz 2.573 GHz 约 13.0%
CPU7 3.302 GHz 2.381 GHz 约 27.9%

然而，在 MagicOS 7.0.0.136 之后荣耀的包管理逻辑拒绝了常规操作，无法通过之前的卸载命令强制卸载。
因此需要通过 Android Binder 接口调用 PackageManager 的 setSystemAppInstallState() 方法，实现系统应用的用户级卸载。

1.先用数据线连通手机与电脑，然后打开设置 → 系统和更新 → 开发人员选项 → 调试 → 勾选USB调试。
2.打开Windows PowerShell，从手机里提取框架文件。

3.打开jadx → open file → 选择adb目录下的framework.jar → 等待jadx完成解析，然后 ctrl+n 搜索类 IPackageManager 找到 android.content.pm.IPackageManager 打开，接着 ctrl+f 搜索方法 TRANSACTION_setSystemAppInstallState 查看真正的 Binder 事务编号。查到本机定义：
